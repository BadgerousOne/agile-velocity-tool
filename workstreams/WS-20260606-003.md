## Problem Statement

The Jira and Azure DevOps integration tabs exist in the UI but contain no real data sync — users must manually export CSV files and import them. This creates friction for every sprint update and blocks the app from becoming a first-class tool for teams already using Jira or Azure DevOps.

---

## Acceptance Criteria

Observable, pass/fail criteria. To be finalized at PLANNING.

- [ ] User can connect to a Jira project (OAuth or API token) and pull sprint data
- [ ] User can connect to an Azure DevOps project (PAT or OAuth) and pull sprint data
- [ ] Sprint data populates velocity tool state without manual CSV export
- [ ] Sync errors are surfaced clearly in the UI with actionable guidance
- [ ] Existing manual/CSV import path is preserved as fallback
