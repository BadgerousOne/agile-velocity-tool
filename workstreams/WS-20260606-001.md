## Problem Statement

The Electron shell is in place but two gaps block shipping to users: (1) the first-launch experience — downloading the default Ollama model — lacks a polished splash window with progress feedback; (2) the macOS universal DMG has not been validated end-to-end, including `electron-builder` config, app icon, notarization, and quarantine removal. Until these are complete the app cannot be distributed as a self-contained desktop product.

---

## Acceptance Criteria

- [ ] First launch shows a splash window with real-time model download progress (bytes downloaded / total, percentage)
- [ ] Splash window closes automatically and the main window opens once the model is ready
- [ ] Subsequent launches skip the splash and open the main window directly (flag-file check via `firstLaunch.js`)
- [ ] `npm run build:dmg` produces a valid universal DMG (arm64 + x86_64) that installs and runs on macOS 13+
- [ ] App icon appears correctly in the DMG and macOS dock
- [ ] Gatekeeper does not block launch (binary is properly signed or quarantine is cleared)
- [ ] `vendor/ollama` binary is correctly unpacked from the asar at runtime

**Acceptance criteria source:** `specs/2026-05-22-electron-conversion.md` / onboarding analysis 2026-06-06
