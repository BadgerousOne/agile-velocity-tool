## Problem Statement

Agent Buddy is fully built but invisible. Users who have never set `buddy_enabled` in localStorage will never encounter it — the Settings toggle is the only entry point, and it is not prominently surfaced. The spec's 40% session-adoption target is unreachable without a discovery mechanism. Additionally, the proactive health signal layer (declining velocity, scope creep, low predictability) only fires when the buddy panel is already open, defeating the "proactive" goal.

---

## Acceptance Criteria

- [ ] A first-time user who has never enabled the buddy is presented with a visible prompt or nudge pointing them to Agent Buddy — without requiring them to navigate to Settings first
- [ ] When the buddy is enabled for the first time, a brief guided experience (one-time message or walkthrough) introduces its capabilities
- [ ] Health signal badges or indicators are visible on the buddy FAB or in the sidebar without the panel needing to be open
- [ ] Existing buddy behavior (chat, sprint creation, dismissible alerts) is unchanged
- [ ] `npm run test:run` remains at 85+ passing tests
