## Problem Statement

Agent Buddy holds conversation history in React component state (`useState`), which is lost on every page reload or Electron window restart. Users lose context mid-session, forcing them to repeat themselves. Persisting history to localStorage would make Buddy feel continuous rather than ephemeral.

---

## Acceptance Criteria

- [ ] Buddy conversation history (messages and timestamps) survives a page reload
- [ ] History is scoped per workspace — switching workspaces shows that workspace's history
- [ ] A "clear history" control lets the user wipe the persisted log
- [ ] Storage is guarded: history is capped at a configurable limit (default: last 100 messages or 512 KB, whichever is smaller)
- [ ] No measurable regression to Buddy startup time or first-message latency
- [ ] Existing Buddy features (Ollama status detection, tool calls, SprintPreviewCard) continue to work
